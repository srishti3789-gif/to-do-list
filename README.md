
# To-Do List Web App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- View total, completed, and pending task counts
- Save tasks using browser Local Storage
- Tasks remain saved after refreshing the page

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Storage

This application uses Local Storage to save tasks in the user's browser. Data is stored separately for each browser and device.
